Student Result Management System

This is a Python-based Student Result Management System developed to manage and calculate student results easily. It stores student details and marks in an Excel file using the OpenPyXL library.

The system can:

- Add student details and marks
- Calculate total marks
- Calculate percentage
- Display PASS/FAIL result
- Store the result in an Excel sheet

Technologies Used: Python, OpenPyXL, Excel
